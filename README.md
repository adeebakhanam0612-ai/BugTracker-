# 🐛 BugTracker - AI-Based Bug Tracking & Developer Productivity System

## 📌 Project Overview
BugTracker is an AI-Based Bug Tracking and Developer Productivity System
built as a DBMS project. It helps IT teams track bugs, assign them to
developers, and monitor developer productivity in real time using a
fully functional web application with database integration.

## 🚀 Features
- 🔐 Secure Login System with Session Management
- 📊 Dashboard with Real-time Bug Statistics
- 📈 Interactive Charts (Pie Chart & Bar Chart)
- 🐛 Bug Report Form with Severity Levels
- 🔍 Search & Filter Bugs by Title, Severity & Status
- ✏️ Update Bug Status (Open, In Progress, Resolved)
- 👩‍💻 Developer Productivity Report with Performance Bars
- 💾 SQLite Database Integration
- 📱 Fully Responsive Design (Mobile, Tablet, Desktop)
